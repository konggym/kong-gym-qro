# Kong Gym · Mi Jungla

Web app para socios de Kong Gym (Mompani, Querétaro).

- `index.html` — la app completa
- `manifest.webmanifest` + `icons/` — permite instalarla en la pantalla de inicio
- `sw.js` — funciona sin internet y se actualiza sola
- `_headers` — configuración de Cloudflare Pages

Publicada con Cloudflare Pages: cada cambio que se sube a la rama `main` se publica solo.
